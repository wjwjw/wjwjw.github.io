# 记忆翻牌 · 配对（memory-match）

一款跑在 Android 电视上的记忆配对小游戏。一屏背面朝上的卡片，先亮几秒让你记住位置，
随后扣下；用遥控器方向键移动高亮框、OK 翻牌，翻到两张一样的图案就配对成功。

## 玩法

1. 每关开始有 **预览时间**（随关卡缩短），所有卡片正面朝上，先记住图案分布。
2. 卡片逐张扣下后进入正式玩法：**方向键 / WASD** 移动高亮框，**OK** 翻开当前格。
3. 翻开两张：

   - 图案**相同** → 配对成功，两张留下绿勾，加分 + 补 2 秒，连击越高加分越多。
   - 图案**不同** → 短暂展示后自动扣回，扣 10 分并清零连击。
4. 全部配对 → 过关（剩余时间 × 8 计入分数）；时间耗尽 → 结束。

返回键：游戏中暂停 / 暂停中继续 / 结算界面回标题。

| --- | --- | --- | --- |
| 1 | 4×3（6 对） | 2.2s | 1.00s |
| 2 | 4×4（8 对） | 2.0s | 0.95s |
| 3 | 5×4（10 对） | 1.8s | 0.90s |
| 4 | 6×4（12 对） | 1.6s | 0.85s |
| 5 | 6×4 | 1.2s | 0.78s |
| 6+ | 6×4 | 逐关再减 0.08s（下限 0.6s） | 逐关再减 0.04s（下限 0.6s） |

最高固定 6×4 = 24 张。再密下去，10-foot 距离下图案就看不清了。

## 实现要点

- **图案全部程序化绘制**（`faces.js`），不用图片素材、不用系统 emoji ——
  目标机型 MiTV4A（Android 6 / WebView ≈ Chromium 47）会把彩色 emoji 渲染成 □。
- **翻牌动画**：卡片先横向缩到 0 再展开，在 `f = 0.5` 处换面；选中框画在缩放之外，
  翻牌时不会被压扁。
- **网格光标**：方向键在 `cols × rows` 格间移动，OK 只作用于当前格 ——
  这类玩法天然「网格 + 时序」，不需要指针（见 `../docs/STANDARD.md` §4）。
- **方向键防抖 110ms**：老 WebView 的 auto-repeat 会一次连跳好几格。
- **预览阶段暂停要补时间**：若在预览中按返回暂停，恢复时把 `peekUntil` 整体后移，
  否则会直接跳到正式玩法、牌还全摊在正面（等于白送答案）。
- **所有动画/计时统一用 `Date.now()`**，rAF 时间戳只用来算 `dt`，两者不混用。

## 兼容性

遵循 `../docs/STANDARD.md`：经典 `<script>`（无 ES module）、无 CSS Grid / `gap` /
`min()` / `clamp()` / `inset` / `color-mix`、无系统 emoji 核心图形。
设计基准视口约 960×540 逻辑像素，画布随 `resize` 自适应。

已在 `tv-h5-app/js/config.js` 的 `games[]` 登记（`completed: true`，icon 用纯字符「记」）。
