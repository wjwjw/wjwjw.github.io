# 掌中灵 H5 游戏 · 像素风图标规范（SPEC v1.0）

> 一套图标，九个游戏。**统一底板 + 统一描边 + 统一高光 + 每枚一个主题色**，
> 只换主体图案，几何规格完全一致 —— 所以摆在一起就是「一套」。

---

## 0. 为什么要这套图标

原启动器 `config.js` 里各游戏的 `icon` 混着用三种东西：emoji（`🎮`）、汉字（`找`/`记`/`问`/`拼`/`蛇`）、
零散 PNG（`dino.png`）。这带来三个问题：

1. **目标设备渲染不了 emoji** —— MiTV4A（Android 6 / WebView ≈ Chromium 47）会把彩色 emoji 画成 `□` 方框（见 `docs/STANDARD.md` §6）。
2. **汉字当图标没有画面感** —— 十个游戏十个不同的字，风格、字重、视觉重心全不一致。
3. **尺寸/风格不统一** —— 旧 PNG 是 72×72 的杂色位图，在 64px 卡片上被缩放，边缘发虚。

本套图标用**同一套几何规则**重做，同时解决风格统一、小尺寸清晰、老设备兼容三件事。

## 1. 几何规格（硬约束）

| 项目 | 规格 |
|------|------|
| 逻辑网格 | **16 × 16** 像素 |
| 底板 | 2 段圆角的方形「贴纸」，占满 16×16 |
| 描边 | **1px**，统一深色 `#2c3650`，四边等宽 |
| 顶部高光 | 描边内侧第 1 行 = 主题色提亮 42%（光源在左上） |
| 底部暗面 | 描边内侧倒数第 2 行 = 主题色压暗 30% |
| 主体可用区 | 居中 **12 × 12**（四周各留 1px 呼吸位，禁止贴到描边上） |
| 描边厚度 | 主体笔画最小 2px（1px 笔画在 64px 下会糊成噪点） |
| 产出 | `SVG`（矢量，`shape-rendering=crispEdges`）+ `PNG` 64 / 128 |
| 主要使用尺寸 | 启动器卡片 **64px**、预览面板 **88px** |
| 清晰下限 | **24px**；16px 时靠底板色 + 剪影辨认（实测可区分九枚） |

### 底板骨架（16×16）

```
row 0   . . K K K K K K K K K K K K . .      ← 2 段圆角
row 1   . K B B B B B B B B B B B B K .      ← B = 主题色提亮（高光带）
row 2   . K A A A A A A A A A A A A K .
 ...                                          A = 主题色（主体区 12×12）
row13   . K A A A A A A A A A A A A K .
row14   . K a a a a a a a a a a a a K .      ← a = 主题色压暗（暗面）
row15   . . K K K K K K K K K K K K . .      ← 2 段圆角
```

主体区局部坐标 `(r, c)` → 全局 `(r+2, c+2)`，所以主体只要画在 12×12 里，天然居中。

## 2. 调色板

### 2.1 四色基座（九枚共用，是「一套」的粘合剂）

| 角色 | 色值 | 用在哪 |
|------|------|--------|
| 描边 / 暗面 | `#2c3650` | 底板描边、墙体、深色镜片、立方体右面 |
| 次级暗面 | `#46527a` | 备用（本套暂未使用） |
| 亮面 / 主体 | `#fffcf2` | 数字、迷宫墙、牌面、蛇身、立方体顶面 |
| 强调金 | `#ffd166` | 主角点、差异点、星星、立方体左面、占位十字中心 |

> `#2c3650` 与 `#ffd166` 不是凭空取的 —— 它们分别是各游戏内部配色的公共交集色与最常用暖色，
> 所以图标和游戏内画面天然同调。

### 2.2 每枚一个主题色

底板色 = 主题色，由脚本按公式派生高光/暗面：
`B = mix(accent, #fffcf2, 0.42)`，`a = mix(accent, #2c3650, 0.30)`。

| 1 | 数字跑酷 | `number-runner` | `#ff8c42` | `config.js` 卡片色 |
| 2 | 迷宫闯关 | `maze-challenge` | `#5a8dee` | `config.js` 卡片色 |
| 3 | 火眼金睛 | `spot-difference` | `#f2a33c` | `config.js` 卡片色 |

| 6 | 拼图乐园 | `puzzle-slide` | `#e0524f` | **游戏内配色**（见下方说明） |

## 3. 九枚图标设计说明

设计原则：**每枚图标 = 底板主题色 + 一个能读出玩法的核心物件**，不做装饰性堆砌。

| 图标 | 核心物件 | 为什么这么画 |
|------|----------|--------------|
| **数字跑酷** | 白色数字「2」+ 三道速度线 | 玩法是「合并相同数字」；数字直接以亮面画在底板上（不加白块），笔画 2px 保证 64px 下不糊。右侧长短不一的横线给「无尽奔跑」的运动感。 |
| **迷宫闯关** | 螺旋迷宫墙 + 正中金块 | 墙体用亮面、走廊即底板色，一眼是迷宫；正中 2×2 金块 =「你在这里」。 |
| **火眼金睛** | 放大镜 + 镜片内金色四角星 | 全套唯一的大暗面（镜片），金色星点压在暗底上最醒目 =「找到了」。 |
| **记忆翻牌** | 两张错位叠放的牌：正面金星 + 背面金徽 | 错位叠放点出「翻」，一背一正点出「配对」。 |
| **小小达人** | 白答题卡 + 深色问号 | 全套对比最高的一枚；问号底部留空一格再点出圆点，小尺寸下不会糊成一团。 |
| **拼图乐园** | 3×3 拼图板：中心空位 + 右下金块 | 深色格线把 2×2 白格切成九宫格；中心露底色 = 空位，右下金格 = 正在推的块。 |
| **贪吃蛇** | L 形蛇身（带眼）+ 红苹果 | 蛇头两只暗眼定住朝向；苹果 5×4 圆润轮廓 + 1px 果柄。 |
| **3D 俄罗斯方块** | 等距立方体（顶 / 左 / 右三面） | 顶面亮、左面金、右面暗 —— 三面三个明度台阶，小尺寸也能读出体积。 |
| **新游戏待定** | 粗十字 + 金色中心 | 中性灰底板不跟任何游戏抢眼，粗十字读作「还会长出新东西」。 |

## 4. 文件与重新生成

```
h5-games/assets/icons/
├── SPEC.md              # 本文件
├── build_icons.py       # ★ 唯一事实来源：调色板 + 九枚图标的像素网格 + 导出逻辑
├── preview.html         # 图标总览页（尺寸矩阵 / 明暗底对照 / 调色板 / 接入片段）
├── <id>.svg             # 矢量，启动器与网页首选
├── <id>.png             # 64×64，兼容兜底
└── <id>@2x.png          # 128×128，高清屏 / 预览面板
```

重新生成：

```bash
cd h5-games/assets/icons
python build_icons.py
```

脚本只依赖 Python 标准库（PNG 编码器手写在脚本里，用 `zlib` + `struct`），
无第三方依赖、无构建链 —— 改图标只要改 `ICONS[].art` 里的字符网格再跑一次。
脚本内置三条断言，防止静默出错：行宽必须是 12、字符必须在调色板里有定义、主体不得越界。

### 字符表

| 字符 | 含义 |
|------|------|
| `.` | 透明（露出底板主题色） |
| `K` / `D` | 统一描边 / 次级暗面 |
| `W` | 亮面 |
| `Y` | 强调金 |
| `A` / `B` / `a` | 主题色 / 提亮 / 压暗 |
| `R` / `r` | 苹果红 / 苹果高光 |
| `T` / `L` / `X` | 立方体 顶 / 左 / 右 面 |

> ⚠️ **踩坑记录**：`T/L/X` 最初写成 `T/L/R`，而 `R` 已经给了苹果红。
> Python 字典里重复的键会**静默覆盖**，结果贪吃蛇的苹果被画成了立方体的暗面（深色方块），
> 渲染出来才发现。现已改名 `X`，并在 `main()` 里加了「字符必须在调色板里有定义」的断言兜底。

## 5. 接入启动器

启动器的 `iconHtml()`（`tv-h5-app/js/launcher.js`）支持两种形态：图片路径（`.png/.jpg/.gif/.svg`）或纯字符。
把 `tv-h5-app/js/config.js` 里各游戏的 `icon` 换成对应路径即可：

```js
{
  id: "maze-challenge",
  title: "迷宫闯关",
  icon: "../h5-games/assets/icons/maze-challenge.svg",   // ← 只改这一行
  folder: "maze-challenge",
  entry: "index.html",
  completed: true,
  color: "#5a8dee",
  tvControls: true
},
```

九枚的完整片段见 `preview.html` 底部的「接入启动器」区块，可直接复制。

**几点说明**

- 路径是相对启动器页面（`tv-h5-app/index.html`）的，`../h5-games/assets/icons/...` 在
  本地（开发机 IP 服务器）与正式（GitHub Pages）两种模式下都能解析 —— 因为两者都是「同一个仓库根」下的绝对结构。
- 优先用 `.svg`：体积 1.2~1.6 KB（比旧 PNG 还小），且任意尺寸都锐利。
  SVG 1.1 + `shape-rendering` 在 Chromium 47 上完全支持。
  若某台设备 SVG 异常，把扩展名换成 `.png` 即可，同一套几何、同一套配色。
- 主页 `index.html` 的作品卡片目前用 emoji（`🦖`/`🔍`/`🧠`…）。同一批图标可以直接替换那里的 `.ico`，
  但主页是「草稿纸手写风」的暖白底，建议先看 `preview.html` 的「明底」对照再决定。

## 6. 扩展：加一个新游戏

1. 在 `build_icons.py` 的 `ICONS` 里追加一项：`id / title / subtitle / accent / motive / note / art`。
2. `art` 画一张 12×12 字符网格（主体保持在 `1..10` 区间内，别贴边）。
3. 主题色挑一个**跟已有九色区分度高**的色相（现有已占：橙、蓝、琥珀、紫、青、红、绿、玫红、灰）。
4. 跑 `python build_icons.py`，打开 `preview.html` 检查 16/24/32px 是否还认得出。
5. 在 `tv-h5-app/js/config.js` 登记时把 `icon` 指向新 SVG。

- [x] SVG + PNG(64) + PNG(128) 三份产物齐备，脚本可一键重建。
