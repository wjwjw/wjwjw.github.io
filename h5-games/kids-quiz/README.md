# 小小达人 · 认知问答（kids-quiz）

一款跑在 Android 电视上的儿童认知问答游戏。屏幕上方给出一张「题目图」，
下面 2×2 四个选项，用遥控器方向键移动高亮框、OK 选定。

## 核心设计：不识字也能玩

低龄儿童不识字，所以**题目全部靠图形传达**：题干是一张图（一个形状 / 一个动物 /
一堆积木），选项是四张图，孩子只要「看哪张和上面一样」就能作答。
界面上那行汉字是给家长看的，不是通关前提。

同时这天然契合电视遥控器：**没有指针也能玩**——方向键在 2×2 里移动，OK 选中当前格，
完全不需要指向或拖拽（见 `../docs/STANDARD.md` §4）。

## 七种题型（按关卡逐步解锁）

| 题型 | 解锁关卡 | 玩法 | 防蒙设计 |
| --- | --- | --- | --- |
| 认形状 | 1 | 找出和上面形状一样的 | 四个选项颜色都不同于题干色，只能靠形状分辨 |
| 认颜色 | 1 | 找出和上面颜色一样的 | 四个选项形状完全相同，只能靠颜色分辨 |
| 认动物 | 2 | 找出一样的小动物 | — |
| 比大小 | 3 | 哪个最大 / 哪个最小 | 四个选项形状颜色相同，只有尺寸不同 |
| 找不同 | 4 | 四个里哪个不一样 | — |
| 数一数 | 5 | 一共有几个？ | 数量随关卡递增（最多 6 个） |
| 找不同（动物） | 6 | 四个动物里哪个不一样 | — |

每关 8 题，时间随关卡递减（110s 起，每关 −5s，下限 60s）。
答对：+100 与连击加成（每级 +20），补 1 秒。答错：−20 分，−3 秒，并**圈出正确答案**。

返回键：答题中暂停 / 暂停中继续 / 结算界面回标题。

## 实现要点

- **出题必须保证答案唯一**：干扰项不能与正确答案重合、也不能互相重合，
  否则孩子选了「看起来也对」的那个却被判错，体验极差。测试里对每种题型都做了断言。
- **单一维度出题**：考形状时把颜色打散，考颜色时把形状统一——
  避免孩子靠另一个维度蒙对。
- **答错要圈出正确答案**：对低龄玩家来说，「知道自己错在哪」比扣分更重要。
- **暂停会把时间还给玩家**：恢复时把 `resolveUntil` 整体后移，
  否则暂停反而成了惩罚（暂停期间倒计时照跑）。
- **所有动画/计时统一用 `Date.now()`**，rAF 时间戳只用来算 `dt`，两者不混用。
- **反馈气泡要两边都留位**：`#toast` 是 DOM、题干和选项是 canvas，两套坐标系互不感知。
  气泡放在 `#hud` 里走文档流会把 canvas 上的题干顶下去；改成 `position:absolute` 后，
  又必须在 `computeLayout()` 的 `bottomPad` 里加 `TOAST_RESERVE` 给它留高，
  否则压住下排选项。`test/layout.js` 专门守这条。

## 兼容性

遵循 `../docs/STANDARD.md`：经典 `<script>`（无 ES module）、无 CSS Grid / `gap` /
`min()` / `clamp()` / `inset` / `color-mix`、无系统 emoji 核心图形。
设计基准视口约 960×540 逻辑像素，画布随 `resize` 自适应。

## 接入启动器

已在 `tv-h5-app/js/config.js` 的 `games[]` 登记（`completed: true`，icon 用纯字符「问」）。
