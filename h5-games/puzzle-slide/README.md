# 拼图乐园 · 滑动拼图（puzzle-slide）

一款跑在 Android 电视上的滑动拼图。一整张画被切成方块打乱，用遥控器方向键
把方块推回原位，右上角常驻一张「目标图」可以随时对照。

## 核心设计：方向键 = 方块滑动的方向

**按的方向，就是方块滑动的方向**：按「右」，空格左边那块就往右滑。
这是低龄玩家最容易建立的心智模型（另一种「方向键 = 空格移动方向」的写法，
孩子按了会往反方向走，很挫败）。这条语义写在 `js/puzzle.js` 的 `sourceIndex` 里，
测试里有专门的断言守着。

棋盘本身是 N×N 网格，方向键天然对应，一次按键走一步，**完全不需要指针**
（见 `../docs/STANDARD.md` §4）。

## 降低挫败感的四个设计

| 设计 | 为什么 |
| --- | --- |
| 打乱 = 从完成态反向走 N 步 | **结果一定可解**。若改成「随机排列再判奇偶」，一半局面无解，孩子永远拼不出来 |
| 右上角常驻目标图 + 按 OK 看大图 | 忘了长什么样随时能看，不卡住 |
| **归位的方块描绿边**、能动的方向描黄边 | 一眼看出「哪块对了」「哪边按得动」，不用靠记忆 |
| 滑不动时棋盘抖一下 + 闷响 | 不看文字也知道这一下没生效 |

每块左上角还标了序号（1..N×N−1），既是拼图参照，也是数序启蒙。

## 关卡

| 关卡 | 棋盘 | 图案 | 时间 |
| --- | --- | --- | --- |
| 1–3 | 3×3 | 6 个场景按关轮换（小房子 / 小猫咪 / 向日葵 / 小汽车 / 小鱼儿 / 小熊） | 200s 起，每关 −14s |
| 4+ | 4×4 | 同上轮换 | 下限 90s |

打乱步数 `min(60 + 关卡×25, 260)`。过关得分 `max(100, N²×100 − 步数×8) + 剩余秒数×6`。

## 实现要点

- **整图预渲染再切片**：`buildPicture()` 把一整张画画进离屏 canvas，运行时每块只做
  一次 `drawImage`。老设备上逐块重绘矢量图形会掉帧。
- **滑动动画**：棋盘数组是「已经移动完」的逻辑状态，动画块单独记录
  `{to, fromR, fromC, toR, toC, start}`，渲染时跳过目标格、按插值位置补画那一块。
  连按时直接丢弃上一次动画（`if (anim) anim = null`），手感更跟手。
- **暂停不惩罚**：恢复时把 `peekUntil` 整体后移，且若是在看图时暂停，恢复后回到看图。
- **所有动画/计时统一用 `Date.now()`**，rAF 时间戳只用来算 `dt`，两者不混用。

## 兼容性

遵循 `../docs/STANDARD.md`：经典 `<script>`（无 ES module）、无 CSS Grid / `gap` /
`min()` / `clamp()` / `inset` / `color-mix`、无系统 emoji 核心图形。
设计基准视口约 960×540 逻辑像素，画布随 `resize` 自适应。

已在 `tv-h5-app/js/config.js` 的 `games[]` 登记（`completed: true`，icon 用纯字符「拼」）。
