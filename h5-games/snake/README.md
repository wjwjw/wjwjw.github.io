# 贪吃蛇 · 小蛇吃果（snake）

一款跑在 Android 电视上的儿童向贪吃蛇。和经典玩法相比做了三处专门为小孩设计的
改造（详见下方「儿童向改造」）：

- **撞墙不死** —— 从另一边钻出来（wrap），避免一次操作就 game over 的挫败感
- **撞自己只掉一颗心** —— 蛇缩短一半、短暂无敌闪烁，还能继续玩；共 3 颗心
- **3-2-1 倒计时 + 方向预选** —— 给孩子反应时间，倒计时里就能先按方向键

## 玩法

1. 用 **方向键 / WASD** 给小蛇转弯，它自己会一直往前爬。
2. 吃到 **红苹果** +10 分、身体变长；偶尔冒出的 **金星** +50 分（限时 7 秒，
   快消失时外圈变红，提示孩子赶紧去吃）。
3. 撞到墙不会死 —— 小蛇会从另一边钻出来。
4. 不小心咬到自己会 **掉一颗心**，蛇缩短一半并短暂闪烁；3 颗心掉光才结束。
5. 连续吃（间隔 < 2.5s）会额外 **手速奖励 +5**，toast 显示「手速真快 +15」。
6. 每吃 6 个苹果升一关，蛇爬得更快（步进从 300ms 降到 120ms 下限）。

返回键：游戏中暂停 / 暂停中继续 / 结算界面回标题。
OK 键：游戏中 = 暂停（其他时候交给按钮焦点激活，不重复处理避免双触发，见 GAME_DEV_GUIDE §2）。

网格固定 20 × 13（每格 ~36px），再密下去 10-foot 距离下苹果就看不清了。

## 儿童向改造

1. **撞墙 wrap**：经典玩法是撞墙即死，小孩最容易在墙角翻车，体验差。
   改成从另一边钻出来后，能持续练习转弯和抢苹果，挫败感大幅下降。
2. **撞自己只掉心 + 缩短 + 无敌闪烁**：身体缩短到 `max(3, floor(len/2))`，
   `HURT_INVINCIBLE = 1200ms` 内身体闪烁、碰撞检查暂时跳过，
   给小孩重新看清局势的时间。
3. **3-2-1 倒计时**：开局的「3」「2」「1」「开始！」大字居中，2.4s 后才真正动，
   期间允许预先排队方向（最多 2 个输入），手忙脚乱的家长也能上手。

## 实现要点

- **帧间插值**：蛇不会「跳」，每步把旧位置写到 `prev`，渲染时按 `stepAcc/stepMs`
  做线性插值；穿墙的那一格直接落位，不做插值（否则会横穿整个棋盘）。
- **蛇身是「一条锥形管」而不是 N 个方块**：先整趟描边、再整趟画身体，每段线宽
  从 `wHead` 收到 `wTail`，颜色取预生成的 48 级色阶（`GRAD`）。
  两个反直觉的坑：
  ① **必须分两趟画**，不能「描边 → 身体」逐段交替 —— 圆头 `lineCap` 会让后一段的
  描边向前一段多探出 `(w+border)/2`，把前一段画好的身体啃出格状缺口；
  ② **描边宽度要跟着身体一起收细**，否则尾巴会变成「细绿线套在粗黑管里」。
- **色阶表预生成**：`GRAD` / `GRAD_HURT` 在加载时算好 48 个 `rgb()` 字符串，
  渲染时按索引取 —— 避免每帧拼字符串，老设备上 GC 压力明显更小。
- **草地用固定种子**：`drawGrass` 用 LCG 而不是 `Math.random`，否则每次 `resize`
  重绘草的位置都会变，电视上旋屏 / 换分辨率会看到草皮「抖」一下。
- **反馈三件套**：吃到东西时同时给「飘字 +10/+50（上浮淡出）+ 扩散圆环 + 蛇头吞咽
  放大」，升关时整块草地泛一层金光 —— 10-foot 距离下小孩靠这些即时反馈理解
  「刚才发生了什么」，比只看 HUD 数字有效得多。
- **长身体时的碰撞判定**：尾巴这一格「正常情况下会让出来」，但 `pendingGrow > 0`
  时尾巴不动，必须一起判，否则能长出重叠的一段（`guard = pendingGrow > 0 ? len : len - 1`）。
- **方向输入队列（最多 2 个）**：方向键快速连按时不会丢输入，同时禁止 180° 掉头
  （蛇头立刻撞到脖子，那是必死操作）。
- **静态背景预渲染**（`prerenderBoard`）：棋盘外框 / 草地 / checker 是一次性的，
  预渲染到离屏 canvas，每帧只 `drawImage` —— 老设备上能省不少开销。
- **AudioContext 安全构造**：无音频设备的环境可能在 `new AudioContext()` 时抛异常，
  用 try/catch 兜住后让 `ctx = null`，所有 sfx 提前 `if (!this.ctx) return`，声音不该把游戏拖崩。
- **覆盖层动画兜底**：覆盖层父节点走 `background-color` 渐入（opacity 恒为 1），
  子卡片走 `opacity + translateY + scale` 渐入 —— 启动器注入的 tv-controls 用
  `opacity === "0"` 判可见性，父节点不能动 opacity（详见 STANDARD §6）。
  同时 `show()` 后 700ms 摘掉 `anim-in` 类，避免弱机动画卡在起始帧。

## 兼容性

遵循 `../docs/STANDARD.md`：经典 `<script>`（无 ES module）、无 CSS Grid / `gap` /
`min()` / `clamp()` / `inset` / `color-mix`、无系统 emoji 核心图形
（心形用 `♥` / `♡` 字符，蛇 / 苹果 / 星全用 canvas 程序化绘制）。
设计基准视口约 960×540 逻辑像素，画布随 `resize` 自适应。

## 调试钩子

URL 带 `#debug` 时，游戏会把内部状态挂到 `window.__snake`：

```js
__snake.state           // 当前状态
__snake.snake           // 蛇身体（数组，head = [0]）
__snake.apple / star    // 苹果 / 金星
__snake.score           // 当前分数
__snake.step()          // 手动走一步（用于 headless 测试）
__snake.setDir(x, y)    // 直接改方向
__snake.forceApple(x,y) // 把苹果钉到指定格子
__snake.startNow()      // 跳过 3-2-1 倒计时，直接 PLAY（并清掉受伤闪烁）
__snake.setAcc(v)       // 调整 stepAcc（截图前拨到半格可截到中间帧）
__snake.render()        // 强制渲染一帧（内部自动补 Date.now()）
__snake.freeze(v)       // 冻结/恢复自动步进 —— 不冻结的话真实循环会继续自动走，
                        // 测试里按步算好的坐标会被它抢先一步
__snake.clearFx()       // 清掉飘字/圆环/金光/红闪/受伤闪烁（取像素前先清，否则会染色）
__snake.layout          // {tile,x0,y0,w,h}，算屏幕坐标用
```

`test/shot.js` 用这套钩子跑按步驱动的冒烟测试（绕开 headless 下不稳定的 rAF 节奏），
覆盖：开始 → 倒计时 → 吃苹果 ×2 → 自咬掉心 → 暂停 / 继续 → 长身体稳定性 →
**像素探针**（直接读 canvas 像素，断言蛇头是亮绿 / 苹果是红色 / 草地是暗绿）。

最后这条探针很值：headless 截图人眼看不方便，但可以让浏览器自己报颜色，
一旦渲染写错（比如 `render(undefined)` 让 `now` 变 NaN、食物直接画不出来）会立刻暴露。
