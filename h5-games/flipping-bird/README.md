# 振翅飞行 · Flipping Bird（flipping-bird）

一款「一键拍翅膀」的飞行小游戏，跑在 Android 电视上也跑在浏览器里。最大特色是
**三套固定配套**：飞机 × 天空、乌龟 × 草丛、鲸鱼 × 海洋，选角色即整套切换，
每套配套各自记录最高分。

## 三套固定配套

| 角色 | 场景 | 障碍 | 画面 |
| --- | --- | --- | --- |
| 小飞机（螺旋桨） | 云上晴空 | 云柱 | 蓝天、太阳、飘云、云海平台 |
| 小乌龟（龟壳 + 红围巾） | 风起草丛 | 灌木丛 | 蓝天白云、远树丛、三层草叶、野花蒲公英 |
| 小鲸鱼（摆尾 + 喷水） | 深蓝海底 | 珊瑚柱 | 水面光束、鱼群剪影、上升气泡、沙质海床 |

角色、场景、障碍、地面、UI 强调色、环境微粒、尾迹材质、BGM 音阶都随搭配变化。
所有画面是 Canvas 矢量绘制，没有图片素材、没有 emoji（目标电视渲染不了彩色 emoji）。

## 玩法

1. 标题页：方向键把光标移到三套配套卡片上按 **OK** 选定；也可以直接用鼠标点。
   - 三套是**固定绑定**的：选「小乌龟 × 草丛」就整套切换，角色与场景结构上无法拆开。
   - 「开始飞行」是 DOM 里的第一个按钮，进页面直接按 OK 就起飞。
2. 游戏中：**OK / 空格 / ↑ / W / 鼠标点击 / 触屏点击**都能拍翅膀；一次按键给一个向上冲量，
   松手就受重力往下掉。
3. 穿过一对障碍柱 +1 分；每 5 分升一段里程，速度略增（有上限）。
4. 撞到柱子或地面掉一颗心，短暂无敌闪烁并把角色挪回缺口中央；**3 颗心掉光才结算**。
   落地后不操作不会被连续扣心：无敌期结束仍贴地会免费小弹一次并提示「快拍一下翅膀！」，
   宽限过后还贴地才扣下一颗（见「儿童向改造」）。
5. **返回键**：游戏中 / 倒计时里暂停，暂停中继续，结算页回标题。

## 儿童向改造

- **撞一次不结束**：3 颗心 + 1.4s 无敌，孩子有时间重新看清局势（与 `snake` 的「撞自己只掉心」同款设计）。
- **落地不「放手即死」**：无敌期结束仍贴地时先免费自动小弹一次（`-320`、**不扣心**），
  再给 800ms 短宽限，期间贴地站立并提示「快拍一下翅膀！」；宽限过了还贴地才扣下一颗。
  每轮掉心后重置、只免一次，不会无限免扣；免费弹期间拍翅膀就能直接救回。
  内部用 `player.groundGrace` 三态区分「首次从空中摔下」与「无敌期刚结束仍贴地」，
  保证第一次触地照常扣心；**无敌期若在空中结束就把标记清回 `none`**，
  否则孩子飞走很久以后的一次普通失手也会白得一次免扣（保护期被无限期携带）。
- **缺口 176 世界单位**、碰撞盒四边各收缩 6px，判定宽容；撞天花板只是贴住，不致死；
  无敌期内触地也只贴地站立，不会沉出屏幕。
- **开局 3-2-1 倒计时**（2.4s），屏幕上同时写明「按 OK 拍翅膀」。
- 速度上限 280、柱间距下限 246，越玩越快但不会快到不可能。
- 相邻柱子的缺口中心位移限制在 ±108，不会出现「上一根在最上、下一根在最下」的必死跳。

## 实现要点

- **绘制与玩法彻底解耦**：`themes.js` 只认 `charId` / `sceneId`，互不引用；固定配套由
  角色下标派生场景下标（`sceneIndex() === charIndex`），结构上不可能拆开；`test/smoke.js`
  会遍历三套固定配套逐一渲染，防止某个绘制分支漏测。
- **静态背景预渲染**：渐变、远山、云带、光束只在 `buildBackdrop()` 里画一次（固定 LCG 种子），
  每帧只 `drawImage`；渲染循环里不创建渐变、不拼 rgba 字符串（STANDARD §10.3）。
- **contain 缩放**：`setWorldTransform()` 先按设备像素铺满 letterbox，再 `setTransform` 到
  960×540 世界坐标。物理参数与窗口尺寸解耦，TV / 桌面 / 手机竖屏都不会变形或跑飞。
- **一键玩法 + 菜单导航共存**：标题与结算页的方向键交给 `TVNav`（standalone）或启动器注入的
  `tv-controls`（空间导航）；一旦开局就主动 `blur()` 焦点，方向键与 OK 全部交回游戏，
  避免启动器抢键。OK 与按钮 click 的双触发用 `startGame()` 的状态守卫兜住。
- **每套配套独立存档**：`localStorage` key 为 `fb-best-<char>`，
  三套配套各有自己的最高分。
- **覆盖层动画**：父层只渐入 `background-color`（父层动 opacity 会让启动器自动聚焦失效），
  子卡片渐入 opacity + 位移；`show()` 后 700ms 摘掉动画类做弱机兜底。
- **返回键陷阱**：`pushState` 占位，每次 `popstate` 后重新占位；启动器内不装（由 launcher 统一处理）。
- **切后台自动暂停**：`visibilitychange(hidden)` 与 `blur` 都会暂停，BGM 不在后台继续，
  恢复必须由玩家手动点「继续飞行」。

## 兼容性

遵循 `../docs/STANDARD.md`：经典 `<script>`（无 ES module）、纯 ES5、无 CSS Grid / `gap` /
`min()` / `clamp()` / `inset` / `color-mix` / CSS 变量、无系统 emoji 核心图形
（生命用 `♥` / `♡` 文字符号）。`test/smoke.js` 内置静态门禁，改一行就能跑。

## 调试钩子

URL 带 `#debug` 时，内部状态挂到 `window.__fb`：

```js
__fb.state / score / level / lives / passed / best
__fb.charIndex / sceneIndex / themeName / WORLD
__fb.player / pipes
__fb.pickCombo(i)                             // 切配套
__fb.startNow()                             // 跳过倒计时直接 PLAY
__fb.forcePipe(x, gapY) / clearPipes()      // 摆一根柱子
__fb.setPlayerY(y) / clearInv() / flap()
__fb.step(dt)                               // 手动推进物理（不受 freeze 影响）
__fb.freeze(v)                              // 冻结主循环的自动步进
__fb.render()                               // 强制渲染一帧
__fb.pause() / resume() / gotoStart()
```

`test/smoke.js` 用这套钩子跑按步驱动的冒烟测试，覆盖脚本加载、三套固定配套渲染、
开局倒计时、物理、得分、掉心（含贴地不沉出屏幕、无敌结束免费小弹不扣心、宽限后才扣心、
保护期不被无限期携带）、结算（含「追平旧纪录不误报新纪录」）、暂停链路、resize 与静态约束，
共 105 项断言。
