**面向儿童的四条硬约束（贯穿全文）**
1. 零随机秒杀：所有伤害必须可预期、可规避。
2. 低挫折：容错高、重开零惩罚、失败画面温柔（"再来一次"而非"GAME OVER"）。

4. 反馈必须"响"：像素小屏下，每次移动/受击/拾取都要有清晰视听反馈（见 §8）。

## 1. Fun Hypothesis（好玩的核心）

> **这游戏好玩的核心是：孩子在每一格里都在做"走捷径挨一下，还是绕远保命"的小赌注——而迷宫把这种权衡变成了一场可以反复重试、没有惩罚的冒险。**

写不清楚就不往下走。这条假说定了，下面所有 pillar 和数值都过它。

## 2. Design Pillars（不可妥协的体验标准）

| # | 支柱 | 含义 | 否决判据 |
|---|------|------|----------|
| P1 | 一拍一反馈 | 每次移动必有视听反馈，孩子靠"手感"而非"读字"理解世界 | 出现"按了没反应"或"受击无提示" |
| P2 | 风险自决 | 伤害可预期可规避，没有随机惩罚 | 出现无法预知的扣血/死亡 |
| P3 | 渐进教学 | 每关至多引入 1 个新机制，前期单机制纯净 | 前 8 关出现 2 个以上新机制叠加 |
| P4 | 角色即情感投射 | 可选角色提供陪伴感，**数值一律公平** | 任何角色带来数值优势（破坏公平性） |
| P5 | 温柔失败 | 死亡只是"再来一次"，进度零损失 | 出现永久失败/惩罚/计时清零挫败 |

## 3. 核心循环（三层钩子）

**Moment-to-moment（0–30s：动作→反馈→决策）**
移动一格 → 触发该格/邻接机制 → 视听反馈（血/位移/状态）→ 决定下一格往哪走。
*设计要点*：单格决策延迟必须 < 0.3s 才有"流畅"感；移动动画时长 `[PLACEHOLDER · 目标 120ms，附动画曲线]`。

**Session loop（2–3min：目标→张力→结果）**
进入关卡 → 扫一眼地图认出机关布局 → 在脑子里规划路线 → 执行中应对怪兽时序/陷阱推力 → 到达终点旗。
*设计要点*：每关都必须存在**零伤可通关的安全路线**（硬规则，保证可解、贴合"温柔失败"）。但"明显"只在低等关卡（L1–L5）：唯一通路即安全线，一眼可见。中高关卡（L6+）安全线仍存在，但被墙/死路/分支掩埋、需探索规划才找得到，难度来自"更短更险的捷径 vs 更长更安全的绕路"的取舍。所有路径必须**弯曲绕行、不得直来直去**（迷宫感来源）。

**Long-term（hours–weeks：进阶→保留钩子→社交）**
解锁新角色（收集动机）、关卡星级（满血到达 = 三星完美）、家长端"已通关地图"。备选社交钩子见 §12。

## 4. 角色系统（5 选 1，纯皮肤 + 差异化音效）

| 角色 | 视觉 | 移动音效 | 设计意图 |
|------|------|----------|----------|
| 小恐龙 | 绿像素龙 | "咚" | 默认推荐，辨识度高 |
| 小猫 | 橘猫 | "喵" | 亲和力 |
| 小狗 | 黄狗 | "汪" | 亲和力 |
| 外星人 | 绿脑袋 | "哔" | 科幻趣味 |
| 刀盾狗 | 持盾狗 | "铛" | "勇敢"人设，孩子最爱选 |

**公平性纪律（P4）**：5 个角色**数值完全一致**（速度、受击、推力均相同）。差异仅在精灵图、待机动画、移动音效。
> *备选（不推荐默认）*：若想给"刀盾狗"一个专属被动（如受击 -0 但不现实，或 -1 改为偶尔免疫），必须在 GDD 写明并破坏 P4 公平性——默认不做，详见 §12。

亲子向彩蛋：每个角色解锁时弹一句趣味小知识（如"恐龙生活在很久以前的地球上"），轻量教育点。

## 5. HP 经济系统（Sources & Sinks）

**模型**：HP 以"爱心"呈现，满血 = **5 颗心** ❤️❤️❤️❤️❤️。每关开局满血；死亡（0 心）→ 温柔重开，零惩罚。

| 类别 | 项 | 数值 | Rationale |
|------|----|------|-----------|
| **Source** | 爱心拾取 | **+1 心（上限 5）** | 只在已受伤时有价值；上限封顶避免囤积通胀 |
| **Sink** | 地刺 | **-1 心** | 单刺为最小惩罚单元，便于儿童计数 |
| **Sink** | 火墙接触 | **-1 心 + 红屏 3s** | 红屏=3 秒警示/无敌，期间重复接触不扣（防连扣） |
| **Sink** | 冰墙接触 | **-1 心 + 冻结 3s** | 冻结无法移动，是"位置惩罚"而非"血量惩罚" |
| **Sink** | 怪兽接触 | **-1 心 + 击退 1 格** | 击退制造位移风险而非纯扣血 |

**通胀审视**：爱心上限 5 = 开局满血，所以爱心不是"无限印钞"，只是"回血通道"，不存在 Source 无 Sink 的通胀漏洞。✅
**容错论证**：5 心 ≈ 允许 4 次失误才死，对 5–10 岁友好；单关 2–3 分钟，重开成本低。
> 全部伤害数值为首发提案，标 `[PLACEHOLDER · 验证路径：§13 Playtest 失败信号 B]`——若实测儿童挫败率 >40% 则下调为 -0（仅状态惩罚）或加心。

## 6. 核心机制规格（每个机制四件套：目的 / 体验目标 / 输入·输出 / 边界·失败态）

### 6.1 基础移动
- **目的**：让孩子用方向键/滑动控制四方向移动。
- **输入**：方向键（桌面）或 上下左右滑动（移动端）；每次移动 1 格。
- **输出**：角色位移 + 播放移动音效 + 更新"朝向"（facing，供香蕉/弹簧使用）。
- **边界**：撞墙不动、不扣血；地图外夹紧。默认初始朝向 = 向下。

### 6.2 爱心（加血）
- **目的**：HP 回源，教孩子"受伤了可以补回来"。
- **输出**：踩入即 +1 心（≤5），播放"叮"音 + 心形弹出动画，随即消失（一次性）。
- **边界**：满血时踩爱心 = 不扣不减（可保留为装饰？→ 默认仍消失，避免误导）。

### 6.3 地刺（扣血）
- **目的**：引入"看见危险要避开"的第一课。
- **输出**：踩入 -1 心 + 刺音 + 红闪。
- **边界**：地刺为静态格，可绕；不可破坏。

### 6.4 香蕉陷阱（踩到向前一格）
- **目的**：教"方向有后果"——你面朝哪，香蕉就把你甩向哪。
- **输出**：踩入 → 沿**当前朝向**强制推进 1 格（推进本身不额外扣血）。
- **边界**：
  - 前方是墙 → 不移动（安全，不扣血）；
  - 前方是地刺/怪兽格 → **会真的踩进去**（风险来源，制造新决策）；
  - 前方是地图边缘 → 夹紧，停在边缘，不扣血。

### 6.5 弹簧陷阱（踩到向后一格）
- **目的**：与香蕉互补，制造"被弹回"的意外与笑点。
- **输出**：踩入 → 沿**朝向反方向**强制推进 1 格。
- **边界**：同 6.4（反向判断墙/边缘/危险格）。

### 6.6 火墙（靠近扣血 + 变红 3 秒）
- **目的**：把"墙"变成主动威胁，教孩子"有些墙不能贴"。
- **触发**：角色处于火墙的**上下左右相邻 1 格**内时触发。
- **输出**：-1 心 + 角色/屏幕泛红 3 秒（红屏期间为警示+无敌，重复接触不扣）。
- **边界**：红屏 3s 倒计时独立于关卡，纯视觉警示；红屏结束恢复。

### 6.7 冰墙（靠近扣血 + 冻住 3 秒）
- **目的**：比火墙更狠——不止扣血，还"定身"，制造位置风险。
- **触发**：同火墙，相邻 1 格触发。
- **输出**：-1 心 + 冻结 3 秒（无法移动，角色变蓝结冰）。
- **边界**：**冻结期间若相邻有怪兽路径 = 高概率挨打**（设计上的进阶风险，L11 后才放手用）；冻结不叠加，刷新为 3s。

### 6.8 小怪兽（固定路径往返）
- **目的**：引入"节奏/时序"维度，让静态迷宫活起来。
- **输入**：每只怪兽绑定一条**路径点列表**（waypoints），沿列表 ping-pong 往返。
- **输出**：与角色同格（或相邻判定 `[PLACEHOLDER]`）→ -1 心 + 击退 1 格 + 怪兽音。
- **边界**：
  - 速度 `[PLACEHOLDER · 目标 1 格 / 0.6s，附手感验证]`；
  - 怪兽有"朝向眼睛"指示器，提前 telegraph 走向（P2 可预期）；
  - 多怪兽互不阻挡（或设定为可互穿，简化实现）。

## 7. 系统交互矩阵（提前暴露系统打架）

| 交互 | 判定 | 说明 |
|------|------|------|
| 香蕉 → 地刺 | Acceptable | 风险点，正是设计意图（L10 教学） |
| 弹簧 → 墙 | Acceptable | 弹回不动，安全 |
| 冰墙冻结 + 怪兽相邻 | **Intended 风险** | 进阶组合，L11+ 才放手 |
| 火墙红屏 + 香蕉推力 | Acceptable | 红屏无敌期内被推，不重复扣 |
| 怪兽击退 → 冰墙 | Bug 风险 | 击退落点可能卡进冰墙触发链，需定义落点优先级（默认：击退优先判定落点安全，落点危险则取消击退） |
| 爱心 + 满血 | Acceptable | 不增减，避免误导（见 6.2） |

## 11. 美术与音乐

**美术（像素风）**
- Tile 基准 16×16 或 24×24，最近邻（nearest-neighbor）放大，禁用抗锯齿保持硬边像素感。
- 调色板：每个角色/机关一套限定色（火=红橙、冰=蓝白、刺=灰、爱心=粉红、香蕉=黄、弹簧=青）。
- 动效克制：受击红闪、结冰蓝覆、陷阱弹跳——用帧动画而非粒子，保性能。

**音乐（电子）**
- 风格：chiptune / synthwave，明快不刺耳（儿童向降高频）。
- 实现：`Web Audio API` 程序化合成或内置 royalty-free 音轨；**首屏需用户手势触发播放**（浏览器自动播放策略），提供静音键。
- 分层：地图 BGM 循环 + 事件 SFX（移动/拾取/受击/通关）独立音轨，便于调音量。
- 关卡张力：后期关卡 BPM 略升（如 L13–15 从 110→128 BPM）制造紧张感。

## 12. 备选 / 扩展建议（供你挑选，不默认实现）

1. **角色专属被动（慎用）**：给刀盾狗"偶发免疫"等，会破坏 P4 公平——默认不做，若要保留"勇敢人设"可用纯视觉（盾牌装饰）代替数值。
2. **家长端**：通关地图、单关用时、护眼提醒（玩 20 分钟弹"该休息啦"）。
3. **故事框架**：轻量剧情"帮小恐龙找回走散的朋友"，每 3 关救一位，给闯关意义（儿童动机强）。
4. **双人本地合作 / 幽灵竞速**：同屏分控或异步影子赛，增重玩性（需重画核心循环）。
5. **关卡编辑器 / UGC**：孩子/家长自己画迷宫，社区分享（扩展寿命，但工作量陡增）。
6. **每日迷宫（Roguelike 轻量）**：每天固定种子生成迷宫，鼓励回流。
7. **Boss 关**：会移动的墙/守卫，作为 L15 后的"周目"内容。
8. **无障碍**：色盲模式（危险不只靠红/蓝，加图标）、撤销一步、提示按钮（消耗星星）。

## 13. Playtest 计划与失败信号（先定义"坏掉长什么样"）

**A（太简单）**：>80% 测试儿童首次满血通关 → 该关加 1 个机关或缩安全路线。
**B（太难/挫败，儿童红线）**：>40% 测试者放弃或喊家长 → 下调伤害（改 -0 仅状态惩罚）或加爱心。
**C（看不懂）**：测试者 2 次内仍不理解某机制 → 加教学牌/预告动画（如 L4 香蕉前放"滑溜溜"提示格）。

**实测必验清单**：移动手感 120ms 是否顺、怪兽 0.6s 是否可被儿童预判、火/冰 3s 是否够反应、推力落点是否如预期（§6.4/6.5 边界）。

## 14. 落地提示（H5 技术，供实现回合参考）

- 网格用二维数组表示关卡（字符映射：`.`空 `#`墙 `S`刺 `H`心 `B`香蕉 `P`弹簧 `F`火墙 `I`冰墙 `M`怪兽 `E`终点 `@`起点），关卡即数据，易扩展 15→20 关。
- 渲染：Canvas 2D（比 DOM 更适合像素 tile 与动画）；移动端 `touchstart` 滑动手势映射四方向。
- 音频：`AudioContext` 在首次 `click/touch` 内 `resume()`，规避自动播放限制。
- 状态机：菜单 → 选关 → 游戏 →（通关/失败）→ 结算；失败即温柔重开。
- 文件结构建议：`index.html` / `js/engine.js` / `js/levels.js` / `js/audio.js` / `assets/`（像素图与音轨）。
