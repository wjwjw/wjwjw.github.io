## 1. 纸面原型判定标准（怎么算"跑通"）

| 判据 | 通过线 |
|------|--------|
| 连通性 | 每关 `@` 与 `E` 任意路径连通 |
| 安全路线 | **存在一条零伤安全路线**（满足 GDD 设计支柱"每关必有可通关安全路线"） |
| 机关被用 | L10 内部捷径、L15 内部全要素区均可从左门走到右门（否则机关是摆设） |
| 决策成立 | L10 / L15 能写出"走险 vs 绕远"的具体抉择（验证 Fun Hypothesis） |

## 2. 关卡数据格式（字符映射，直接可落地）

| 字符 | 含义 | 类别 |
|------|------|------|
| `#` | 普通墙（不可走） | 墙 |
| `F` | 火墙（不可走；正交相邻扣血+红屏3s） | 墙+危害 |
| `I` | 冰墙（不可走；正交相邻扣血+冻结3s） | 墙+危害 |
| `.` | 地板 | 地面 |
| `@` | 起点 | 地面 |
| `E` | 终点 | 地面 |
| `S` | 地刺（-1 心） | 危害地面 |
| `H` | 爱心（+1 心≤5） | 增益地面 |
| `B` | 香蕉（踏入→沿朝向推进1格） | 机关地面 |
| `P` | 弹簧（踏入→沿朝向反推1格） | 机关地面 |
| `M` | 怪兽（本纸面用单独路径记号，见 §5） | 动态 |

> 关卡即数据：实现时把每关存成字符二维数组，引擎按本映射渲染与解析，扩 15→20 关零成本。

## 3. 核心解析流程（每次移动引擎要做的事，文本版状态机）

```
玩家输入方向 →
  1) 计算目标格 = 当前格 + 方向
  2) 目标格是墙(#/F/I)？ → 不移动，播放"撞墙"音，结束
  3) 移动到目标格
  4) 目标格是 B/P？ → 计算推力落点 = 目标格 + (朝向 / 反朝向)
       落点是墙？ → 取消推力，原地不动（安全，不扣血）
       落点是 S？ → 移动到落点并触发地刺(-1)   ★风险来源
       落点是 B/P？ → 移动过去，但【不连锁触发】（单向触发）
       否则 → 移动过去
  5) 检测正交相邻是否有 F/I → 有则触发对应扣血+状态（红屏/冻结3s，期内重复接触不扣）
  6) 检测与怪兽同格 → 触发 -1 + 击退1格（落点危险则取消击退，原地-1）
  7) 到达 E？ → 通关结算（满血到达=三星）
```

## 4. 代表关地图（已通过 BFS 验证）

### L1 教学关（9×9，仅教四方向移动，无机关）
```
#########
#@......#
#.###.#.#
#.#...#.#
#.#.###.#
#...#...#
###.#.###
#......E#
#########
```
**安全路线**：`@(1,1)` → 右沿 row1 到 `(1,7)` → 下沿 col7 到 `(7,7)=E`。全程零机关。
**决策点**：无（教学关刻意零决策，只验证"控制可学"）。风险/趣味从 L2 起逐步加载。

### L10 推力谜题（11×11，香蕉+弹簧）
```
###########
#@........#
#.#######.#
#..BB.SB#.#
#.#.SPS.#.#
#.#BS.BB#.#
#.#.SPS.#.#
#.#BB.SB..#
#.#######.#
#........E#
###########
```
- 左门 `(2,3)`、右门 `(8,7)` 通向内部 B/S/P 捷径区。
- **安全外环**：`@` → 右沿 row1 → 下沿 col9 → `E(9,9)`，零机关。
- **危险捷径（内部）**：进入左门后即踩 `(3,3)=香蕉`。内部香蕉/弹簧布局刻意制造"朝向决定生死"：

| 位置 | 机关 | 朝向→落点 | 后果 |
|------|------|-----------|------|
| `(3,5)=B` 香蕉 | 朝右推→`(4,5)=S` | **-1 心（风险）** | 错误朝向送你进刺 |
| `(3,5)=B` 香蕉 | 朝下推→`(3,6)=.` | 安全 | 正确朝向避险 |
| `(6,4)=P` 弹簧 | 朝右推→左回`(5,4)=.` | 仅浪费步数 | 弹簧多为"弹回"喜剧 |
| `(6,6)=P` 弹簧 | 两侧落点均地板 | 安全弹回 | — |

**决策点（Fun Hypothesis 成立证据）**：玩家面临"绕外环绝对安全但慢" vs "穿内部捷径快但必须规划每个香蕉的朝向，否则被推进刺里扣心"。这正是"走捷径挨一下，还是绕远保命"的小赌注。

### L15 全要素汇演（15×15，含刺/心/香蕉/弹簧/火墙/冰墙/双怪兽）
```
###############
#@............#
#.###########.#
#...........#.#
#.#.H.S.B.S.#.#
#.#S.P.H.P.S#.#
#.#.........#.#
#.#.B.S.I.S.#.#
#.#.........#.#
#.#.S.H.F.H.#.#
#.#.........#.#
#.#P.S.B.S....#
#.###########.#
#............E#
###############
```
- 左门 `(2,3)`、右门 `(12,11)` 通向内部全要素区。
- **安全外环**：`@` → 右沿 row1 → 下沿 col13 → `E(13,13)`，零伤。
- **全要素内环（ intended 路线）**：
  - 爱心缓冲：`(5,4)H`、`(7,5)H`、`(5,9)H`、`(9,9)H` 共 4 颗，可在闯机关前攒血。
  - 火墙 `(7,9)F`、冰墙 `(7,7)I`：其正交相邻格为"禁区"，玩家需绕行（制造路线规划）。
  - 双怪兽（见 §5）把内部分成时序格子，横穿必须等节拍。
- **决策点**：安全外环（无聊但稳） vs 全要素内环（快+满血通关拿三星，但要同时做三件事：躲刺、绕火/冰禁区、卡怪兽节拍、用香蕉时控朝向）。多重小赌注叠加 = 汇演关该有的密度。

## 8. 纸面结论

**Fun Hypothesis 是否成立？**
- L1：教学关，零决策（预期），验证"控制可学"。
- L10：**成立**——外环安全慢路 vs 内部香蕉捷径（朝向决定推入刺与否），是标准"走险 vs 绕远"小赌注。
- L15：**成立**——安全外环 vs 全要素内环（刺+火/冰禁区+双怪兽节拍+爱心缓冲多重叠加），密度达标。
- 三关**均可通关且必有零伤安全路线**（设计支柱达成）。**纸面原型 PASS。**

**待决问题（redraw risk / 需实现后 playtest 解决）**
1. **数值仍是 `[PLACEHOLDER]`**：怪兽速度、火/冰 3s、移动 120ms、各伤害 -1 均未经实测，按 GDD §10 建 tuning 表，实现后跑儿童 playtest。
2. **冰墙+怪兽 combo 当前未触发**（L15 冰墙 `(7,7)` 邻接格未与怪兽路径重叠）。两种处理：①实现时把怪兽 B 路径右移一列擦过冰墙邻接格，激活该进阶风险；②或明确该 combo 留到 GDD 的 L11 教学关，本关不强制。★ 建议实现时二选一明确。
3. **推力触发语义**（边界 #9）：建议实现采用"仅输入踏入触发、被推落入不触发"的单向规则，写入引擎注释。
4. **儿童容错红线**：若 playtest 挫败率 >40%（GDD §13 信号 B），把伤害从 -1 改为 -0（仅状态惩罚）或加心。
