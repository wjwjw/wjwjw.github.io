# 火眼金睛 · 找不同（spot-difference）

左右两幅并排的画，右图藏着若干处差异，用取景框把它们全找出来。

- 入口：`index.html`（**直接双击即可运行**，不依赖启动器）
- 已在 `tv-h5-app/js/config.js` 登记（`completed: true`）

## 玩法

1. 方向键 / WASD 移动取景框，OK 标记可疑之处。
2. 点对：+100 分，连击每次额外 +30，并回 1.2 秒。
3. 点错：-30 分，扣 3 秒。
4. 找齐本关全部差异即过关，剩余时间按 10 分/秒折算奖励。
5. 时间归零则本局结束。

暂停菜单（返回键 / `Esc`）里有「提示」，会圈出一处未找到的差异，代价是 20 秒。

## 差异是怎么造出来的

场景不用任何图片，全部由 Canvas 2D 矢量绘制，每局随机生成。差异由以下五种手法产生：

| 手法 | 说明 |
| --- | --- |
| `recolor` | 改颜色（房屋改的是屋顶色） |
| `resize` | 放大到 1.34 倍或缩到 0.68 倍 |
| `move` | 平移一段距离（原位置与移动后位置都能判中） |
| `remove` | 右图里整件东西消失 |
| `add` | 右图里凭空多出一件东西 |

每关的手法配比是**预先排好的**（`kindPlan`），保证一关里同时出现多种破绽，而不是随机到
整关全是变色：

| 关卡 | 差异数 | 场景物件数 | 限时 | 已解锁手法 |
| --- | --- | --- | --- | --- |
| 1 | 5 | 14 | 84 秒 | 变色 / 大小 / 平移 |
| 2 | 6 | 16 | 79 秒 | + 凭空多出 |
| 3 | 7 | 18 | 74 秒 | + 消失 |
| 5 | 9 | 22 | 64 秒 | 以上全部，比例更偏向「多出 / 消失」 |
| 8 | 12 | 24 | 49 秒 | 差异数上限 12、物件数上限 24 |
| 12 | 12 | 24 | 44 秒 | 限时下限 44 秒 |

## 关卡主题

每关换一套天色，循环使用（`THEMES`），画面观感不会重复：

| 主题 | 特征 |
| --- | --- |
| 晴朗 | 蓝天白云，太阳 + 光芒 |
| 黄昏 | 橙金色天空，暖褐色山丘与草地 |
| 夜晚 | 深蓝夜空 + 星点，太阳换成**月亮**（带光晕和环形山） |
| 春天 | 淡青天空，嫩绿草地 |
| 秋天 | 灰蓝天，金黄草地 |

场景物件共 **20 种**：太阳 / 月亮 / 云 / 小鸟 / 气球 / 星星 / 风筝 / 蝴蝶 / 蜻蜓 / 蜜蜂 /
房屋 / 树 / 路灯 / 路牌 / 栅栏 / 灌木 / 树桩 / 石头 / 蘑菇 / 花。
其中太阳和月亮是每幅画的锚点，**不参与差异抽取**。

## 为什么是「取景框网格」而不是鼠标指针

电视遥控器只有方向键 + OK，没有指针（见 `../docs/STANDARD.md` §4）。
所以把画面切成 7×4 网格，取景框吸附在格子上，方向键可靠可达、不会丢焦点。
鼠标 / 触屏点击是**附加**操作（点哪测哪），不是唯一玩法。

**关键设计：物件直接按格子中心生成。** 生成场景时先建一张 7×4 的空格子表，一格只放
一件东西，位置取「格子中心 ± 0.22 格」的小抖动。这样每个物件都待在取景框正中间，
方向键移过去时破绽就落在框子中央 —— 「居中选中」，而不是卡在框子边角上；
同时大小、颜色、种类都是随机的，画面也不会变成死板的棋盘格。

地平线固定在 `h = 0.62`，让取景框第 2 行（中心 0.625）正好压在草地上、第 3 行（中心
0.875）在草地中部 —— 地面物件吸附到格子中心后不会「浮在半空」。
`move` 类差异的位移被限制在「同一格内」，所以原位置和移动后的位置用同一个格子按 OK 都能判中。

## 过关过渡

找齐最后一处差异时**不会立刻弹结算卡片**（`CLEAR_DELAY = 950ms`）：

1. 进入 `RESOLVE` 过渡态 —— 计时冻结、输入锁住，玩家能看清最后那枚绿圈勾；
2. canvas 上叠一层半透明的绿色过关光晕 + 从最后一处差异扩散出去的双环 + 「全部找到！」；
3. 之后结算卡片以 0.44 秒的渐入动画淡入（`.overlay.anim-in`），过关界面整体半透明，
   能透出底下的画面。

动画类由 JS 在 700ms 后摘掉作为兜底：即使老设备主线程被绘制循环占满、CSS 动画没能推进，
元素也会回落到「完全可见」的基础样式，绝不会停在半透明状态。
过渡期间按 OK（或点一下画面）可以跳过动画直接看结算。

## 兼容性

目标机型 MiTV4A（Android 6 / WebView ≈ Chromium 47），因此：

- 全部用经典 `<script>` + IIFE，**不使用 ES module**。
- 不用 `grid` / `gap` / `min()` / `clamp()` / `inset` / `color-mix()`。
- 画面里**不使用系统 emoji**（会渲染成 □），一律 canvas 矢量绘制。
- 静态画面预渲染到离屏 canvas，每帧只叠标记与取景框，减轻老设备负担。
- 方向键 auto-repeat 有 110ms 防抖，避免一次连跳多格。
