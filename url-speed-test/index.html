网页 URL 测速工具

两种模式：
① 自动提取：输入网址，抓取页面提取所有链接（依赖 CORS 代理，国内经常连不上）
② 手动列表：直接粘贴 URL 列表（每行一个），不需要任何抓取通道，测真实连接延迟
拿链接列表最省事的办法：用下面的「提取本页链接」书签，在目标页面上点一下，全部链接就进剪贴板了

HTML 解析范围：href/src/srcset/data-*/form action 属性、meta refresh、CSS url()、<script> 字符串内 URL。 第一行写 # 来源页 URL → 支持相对路径（/a/b、?q=1）；不填时也接受 //cdn.x.com/... 协议相对。
抓取通道设置（自动提取失败时点开这里）
2026-09-11 实测：公共 CORS 代理已基本全灭。corsproxy.io 要 API key、codetabs 返回 522、 cors.lol 与 cors.eu.org 限流、yacdn / thingproxy / r.jina.ai 直接连不上， whateverorigin 和 corsproxy.org 返回的是它们自己的页面。目前只剩两个还有机会： corsfix（仅本地打开时可用，实测 0.3~2s）和 allorigins（8~21s，成功率约 1/3）。
结论：自动提取基本指望不上。公共代理不稳定，这条路只当兜底。
真正可靠的路子是绕开代理：用下面的「书签提取」（在目标页面上点一下书签，链接直接进剪贴板）， 或者切到「手动 URL 列表」模式粘贴。两条路都不走网络、不踩 CORS、不需要任何部署。
点上面的按钮逐个探测当前哪些通道还能用。全灭时请改用「手动 URL 列表」模式或书签提取，不依赖任何代理。
书签提取（手动模式专属 · 免代理 · 手机也能用）
提取本页链接 长按链接 → 复制 / 添加到书签
  1. 长按绿色按钮 → 添加到书签（或拖到书签栏）
  2. 在目标页面上点书签 → 链接列表自动复制到剪贴板
  3. 回到本页 展开粘贴框 → Ctrl+V → 开始测速
提取的是渲染后的真实链接（JS 动态生成的也能抓到）；列表第一行 # 网址 会被识别为来源页，用以过滤同站地址。全程在浏览器里完成，不走服务器、不踩 CORS。

首包 = 该地址第 1 次请求的耗时；稳定值 = 后续采样的中位数（连接已复用），排名按稳定值。
只有每个域名的第一个地址，首包才真正含 DNS / TCP / TLS 握手；同域后续地址复用连接，首包会显示为更淡的灰色，别拿它当握手开销。
测的是响应首字节到达的时间，不含整包下载；同一域名串行测试，避免互相抢连接；鼠标悬停某行可看中位数 / 最快 / 最慢。
